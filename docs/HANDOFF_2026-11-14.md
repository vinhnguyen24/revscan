### 1.3 Calibrate thật (gateway nội bộ + Ollama)

- Hỗ trợ **Ollama Cloud** qua `OLLAMA_API_KEY` (base `https://ollama.com/v1`) và mọi
  gateway OpenAI-compatible qua `OPENAI_BASE_URL`.
- `--ai` sửa để chạy được với gateway thật:
  - `"stream": False` (gateway stream SSE mặc định → JSON parse fail).
  - `max_tokens` 400 → 1200 (`TRAPKEY_AI_MAX_TOKENS`; reasoning model ăn hết token,
    `content` rỗng).
  - Prompt đổi từ "write a keygen/patch" (bị model từ chối) sang **audit: locate the
    check + describe algorithm**.
  - Success chỉ tính khi `FUNCTION:` là tên/địa chỉ thật; `none`/`unknown`/
    `undetermined`/`unresolved` = fail; chỉ lấy token đầu của dòng.
  - Pack gửi kèm `license_named_functions` + `license_strings` (đúng thứ agent grep).
  - `--repeat N`: median qua N lần (call đầu batch bị cold-start, từng là outlier ~3x).
  - `calibrate.py` tự pop `TRAPKEY_CALIBRATION_K`/`MODEL` để `k` cũ không lẫn vào fit.
  - Fit cuối: `workload = prompt_tokens/prefill + completion_tokens/decode`,
    `k = measured / workload` → `k` là **speed factor thuần**.

## 6. Bổ sung phiên này (disassembly trong evidence pack)

Việc #1 của §3 đã xong. Pack gửi model giờ có **code thật**, không chỉ strings:

| File | Việc |
|---|---|
| `scanner/il.py` | IL decoder đầy đủ (1-byte + 0xFE), resolve token: `ldstr` → chuỗi thật, `call` → `Type::Method` |
| `scanner/native.py` | objdump: tìm instruction reference licence string (rip-relative) → lấy hàm chứa nó; annotate mọi `# 0x...` thành string/import name |
| `scanner/dotnet.py` | thêm `method_body()`, `user_strings()`, `resolve_token()`, TypeRef/Field/MemberRef; sửa **HeapSizes `base+6`** |
| `scanner/ai.py` | `build_pack` chèn code trước string dump; `TRAPKEY_AI_CODE=0` để tắt; `measure()` trả `code_chars` |

Chọn hàm (theo thứ tự ưu tiên, tối đa 4):
licence string xref → crypto import xref → named export → entry point.
.NET: method load licence string (`ldstr`) → method tên licence.

Đo thật (máy này, Ubuntu, objdump 2.42):

| Binary | Pack code | Objdump pass |
|---|---:|---:|
| `notepad.exe` (0.2 MB) | 251 chars (entry point) | 0.1 s |
| `WinRAR.exe` (3 MB) | 4.5 KB, 2 hàm (`License=%s`, `CryptAcquireContextW`) | 0.7 s |
| `System.dll` (.NET) | 10.5 KB, 4 method body | 0.1 s |
| `mscorlib.dll` (.NET) | 4.4 KB, 4 method body | 0.6 s |

Test: `tests/test_disasm.py` (14) — decoder thuần (không cần binary) + metadata align +
objdump skip nếu thiếu. Scanner thêm 4 test cho `grounded_answer`. Tổng 116.

**Bug phát hiện khi làm**: `HeapSizes` bị đọc ở `base+7` (Reserved2) thay vì `base+6`.
Với assembly có heap 4 byte, toàn bộ bảng lệch → tên method rác và `license_methods`
rỗng. Fix này làm `dotnet_il_bytes` và budget .NET đổi → **phải re-fit `k`**.

**Success của `--ai` giờ phải grounded**: `FUNCTION:` phải là tên có trong pack hoặc địa
chỉ nằm trong image; model trả `ValidateKeyName` (không tồn tại trong evidence) trước đây
vẫn tính success. Prompt cũng yêu cầu chỉ nêu hàm có trong evidence. Đo thử 2026-11-14:
mscorlib trả `ValidateKeyRights` (có trong pack) → grounded=true, 3.7s; WinRAR trả
`0x14006c620` (hàm crypto có trong pack) → grounded=true, 5.4s.

**Precision `is_license_ident`**: thêm `CONTEXT` (name/mode/value/size/rights...) và đếm
weak **distinct**. `ValidateKeyName`, `GetBaseKeyFromKeyName` không còn khớp;
`TrialDivisionBounds` vẫn khớp (trial) — chấp nhận.

Chưa làm: capstone (không cài, objdump là đủ và optional); chưa đo bằng model frontier
(cần key/model); pack vẫn chưa có call graph giữa các hàm.
